# Legacy UI

Diseño anterior de la interfaz, conservado únicamente con fines de referencia.

- `gui_legacy.py` — versión previa de `gui.py` (diseño antes del rediseño v1.1.0).
- `styles.qss` — hoja de estilos correspondiente a `gui_legacy.py`.

No es usado por la aplicación principal (`main.py` usa `gui.py`). Este directorio
no se incluye en la compilación del ejecutable.
